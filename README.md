# Catalyst EB-5 Services

Static site for Catalyst Capital Management’s EB-5 construction administration and loan servicing business. Built exactly the way catalystcd.com is built: plain HTML generated by a Python script, no framework, no `node_modules`, no dependencies.

```
build.py                  generator, run: python3 build.py
content/*.json            all site content
static/                   stylesheet, scripts, redirects, processed images
static/tea-map.js         the TEA Map tool
netlify/functions/acs.mjs optional Census data proxy for the TEA Map
tools-process-images.py   turns source-photos/ into static/img/ (needs Pillow, run locally)
source-photos/            original photography and images pulled from the 2026 deck
EDITING.md                how to change site content
netlify.toml              build config
dist/                     generated output, do not edit
```

## Deploy to Netlify

### Recommended, connect the repo

Push this folder to the new GitHub repository, then in Netlify choose **Add new site, Import an existing project**. `netlify.toml` sets everything:

- Build command: `python3 build.py`
- Publish directory: `dist`
- Python 3.11
- Functions directory: `netlify/functions`

Every push rebuilds and deploys. Every pull request gets its own preview URL.

### Fastest, drag and drop

```bash
python3 build.py
```

Drag the `dist` folder onto the Netlify dashboard. Good for a preview. (The TEA Map still works without the function; it falls back to public data.)

### Custom domain

`content/site.json` sets `"url": "https://eb5.catalystccm.com"`, a placeholder. Change it to the real domain before launch; it drives canonical URLs, social cards and `sitemap.xml`. A subdomain of catalystccm.com is the simplest option: add a CNAME record for `eb5` pointing at the Netlify site, and leave the root domain and MX records untouched.

## What is wired up

**Pages.** Home, Services, Track Record, TEA Map, Info Center (26 articles, each with its own page), About, Contact, plus Thank You, Privacy, Terms and 404.

**TEA Map.** Address search or map click. Finds the census tract and every directly adjacent tract, pulls ACS unemployment, computes the best qualifying combination (labor-force weighted, against 150% of the national rate), lets the user add or remove tracts, and runs the rural test (outside any metro area and outside any city of 20,000+ per the 2020 Census). Results can be copied as a text summary. Deep link: `/tea-map/?address=2000 Main St, Fort Myers, FL`.

- Boundaries, metro areas and city populations come from U.S. Census Bureau TIGERweb. Public, no key.
- Unemployment comes from the Census Data API through `netlify/functions/acs.mjs` **when a key is set**, otherwise from Esri Living Atlas ACS layers. Public, no key, but that layer lags the Census release (it currently serves an older 5-year vintage).
- **To use the newest Census data:** get a free key at https://api.census.gov/data/key_signup.html, then in Netlify go to **Site configuration, Environment variables** and add `CENSUS_API_KEY`. Redeploy. The map shows which vintage it used under every result.
- Leaflet loads from cdnjs; map tiles are CARTO light. No accounts or keys.

**Info Center.** Category chips filter the library in place and update the URL (`/info-center/?category=updates`), the same pattern as the Civitas info center. Each article has related articles, a proposal call to action and a link to the TEA Map. A glossary sits under the library.

**Netlify Forms.** Two forms, both with a honeypot: `contact` (with organization, role, engagement model, project location and loan amount) and `updates` (newsletter signup on the Info Center). Submissions appear under **Forms** in the Netlify dashboard; set notification emails under **Forms, Notifications**. Both redirect to `/thank-you/`.

**SEO.** Unique title and description on every page, canonical URLs, Open Graph and Twitter cards, `sitemap.xml`, `robots.txt`, JSON-LD (FinancialService, AboutPage, ContactPage, CollectionPage, Article).

**Accessibility and performance.** Same as catalystcd.com: skip link, focus rings, ARIA on the nav toggle, `prefers-reduced-motion`, bios as native `<details>`, lazy-loaded responsive WebP with JPEG fallback, one stylesheet, one site script, immutable caching on `/assets/`.

## Decisions to confirm before launch

1. **$180 million vs. the loans shown.** The 15 representative loans (excluding the current $32 million West Palm Beach mandate) add up to $196.84 million, more than the $180 million tile. The build prints this as a note. Either some of those loans were partly EB-5 funded, or the tile should read higher. Same numbers as the deck, so the site matches it for now.
2. **Developer figures.** The deck says $365M+ completed and 1,881 units; catalystcd.com computes $343 million and 1,785 delivered units from its project records. This site uses the deck. Pick one so the two sites agree.
3. **Section Q.** The risk card and draw cycle use the deck’s wording (affiliated JCE confirms to the fund administrator within 30 days that a construction consultant verified each deployment). Have EB-5 counsel confirm the statutory reference and wording, since it is a specific legal claim on a public page.
4. **Loan photos are small.** The deck images top out around 400 pixels wide. They hold up in the four-column grid but would benefit from originals.
5. **Reid Jaeger’s title.** The deck says Director; catalystcd.com says Managing Director of Real Estate Development.
6. **Info Center review.** Articles are current as of October 21, 2026 (fee rule effective November 30, 2026; investment adjustment January 1, 2027; program authorized through September 30, 2027). Have counsel review before launch, and update `investment-amount-adjustment-2027` when USCIS publishes the new amounts.
7. **Privacy and Terms** are placeholders. Replace with counsel-approved language.
8. **LinkedIn** points to the Catalyst Community Development company page.

## Local preview

```bash
python3 build.py
cd dist && python3 -m http.server 8000
```

Open http://localhost:8000. The `/api/acs` function only runs on Netlify (or `netlify dev`); locally the TEA Map uses the Esri fallback automatically.
